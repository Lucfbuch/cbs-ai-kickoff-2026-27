# CBS AI Internal Kickoff 2026/27

Slide deck for the CBS AI new member kickoff. Plain HTML, CSS and JavaScript, with no build step.

## Presenting

Open `index.html` in Chrome (keep the `assets` folder next to it), or use the GitHub Pages link if enabled.

| Action | Keys |
|---|---|
| Next slide | → ↓ Space Page Down |
| Previous slide | ← ↑ Page Up |
| First / last slide | Home / End |
| Fullscreen | F |
| Jump to a section | Click a part on the agenda slide |

Fonts load from Google Fonts, so open the deck once while online before presenting. If macOS "Reduce Motion" is on, transitions are turned off.

## Adding the new website link

In `index.html`, find this line near the bottom and paste the address between the quotes:

```js
var WEBSITE_URL = '';
```

The website slide's button and address bar update automatically.
